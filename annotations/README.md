# 墨读标注 · Inkstone Annotations

为 Obsidian 笔记提供下划线、四色高亮和备注操作。选中文字后，在右键菜单或命令面板打开「墨读：标注与备注」，选择标记并填写备注，内容直接保存在当前 Markdown 文件中。

这是 Inkstone 1.2.0 的可选配套插件，插件版本为 1.0.0。Inkstone 主题仍是纯 CSS；只安装主题也可以阅读已有标记。插件使用本地 Obsidian API，不调用网络，不需要账户或其他插件。

## 安装

将插件目录中的 `main.js`、`styles.css` 和 `manifest.json` 放到笔记库的以下位置：

```text
你的笔记库/
└── .obsidian/
    └── plugins/
        └── inkstone-annotations/
            ├── main.js
            ├── styles.css
            └── manifest.json
```

打开「设置 → 第三方插件」，关闭「受限模式」，然后启用「墨读标注 Inkstone Annotations」。安装后没有出现在列表中时，重启 Obsidian，并检查目录是否多嵌套了一层。

主题与标注合集包包含 `themes/Inkstone/` 和 `plugins/inkstone-annotations/` 两个目录，分别复制到笔记库的 `.obsidian/themes/` 和 `.obsidian/plugins/` 下。单独的主题包不包含 JavaScript，也不会添加标注菜单。

`.obsidian` 是隐藏目录。使用自定义配置文件夹时，请替换为实际文件夹名。

## 添加标注与备注

1. 在笔记中选中同一行的普通文字。屏幕上自动折行不影响选择，但不要跨越手动换行。
2. 右键选择「墨读：标注与备注…」，或在命令面板中搜索「墨读：标注与备注」。也可以点击左侧的荧光笔图标。
3. 选择下划线，或黄色、绿色、蓝色、粉色高亮。
4. 按需填写备注，点击「保存标注」。也可以按 `Cmd+Enter`（macOS）或 `Ctrl+Enter`（Windows/Linux）保存。

备注会作为原生脚注追加到当前文件文末，正文标记后显示脚注编号。在阅读视图中点击编号可跳转到备注，脚注处的返回链接可回到正文。

命令面板还提供快捷操作，可以在「设置 → 快捷键」中自行绑定按键：

| 命令 | 操作 |
| --- | --- |
| 墨读：添加下划线 | 为选中文字直接划线 |
| 墨读：黄色高亮 | 直接添加黄色高亮 |
| 墨读：绿色高亮 | 直接添加绿色高亮 |
| 墨读：蓝色高亮 | 直接添加蓝色高亮 |
| 墨读：粉色高亮 | 直接添加粉色高亮 |
| 墨读：添加备注 | 打开面板填写备注，并给原文添加下划线 |
| 墨读：切换彩色／灰阶标注 | 切换当前显示方式 |
| 墨读：撤销上次标注 | 撤销插件刚刚添加的标注 |

在编辑视图中也可以使用系统撤销：`Cmd+Z` 或 `Ctrl+Z`。阅读视图请使用「墨读：撤销上次标注」。该命令只保留本次启用插件以来的最后一次标注；若文件随后有其他修改，请切换编辑视图使用系统撤销。取消面板不会写入标注。

## 彩色与墨水屏显示

默认使用浅色高亮底色，正文保持深色。开启面板或插件设置中的「墨水屏显示」后，四色统一使用浅灰底，并通过线型保留区别：

| 标注 | 线型 |
| --- | --- |
| 黄色 | 实线 |
| 绿色 | 双线 |
| 蓝色 | 点线 |
| 粉色 | 虚线 |

切换显示不会改变 Markdown 中保存的颜色，之后仍可恢复彩色。标注操作依赖插件启用；插件关闭后，Inkstone 主题仍能显示保存的 HTML 标记与原生脚注。

## 保存格式与适用范围

下划线和高亮使用 HTML，备注使用 Obsidian 原生脚注，例如：

```md
<u class="inkstone-underline">需要回头思考的句子</u>[^inkstone-demo-1]

<mark class="inkstone-highlight inkstone-yellow">值得记住的观点</mark>

[^inkstone-demo-1]: 我对这句话的理解。
```

高亮颜色类名分别为 `inkstone-yellow`、`inkstone-green`、`inkstone-blue` 和 `inkstone-rose`。这些标记在阅读视图中显示；编辑视图可能显示 HTML 标签，插件没有添加实时预览装饰。可以直接编辑源码修改或删除标记与脚注。

请以同一行的普通正文为操作范围。代码、公式、属性、跨行选区及完整的 Markdown 或 HTML 格式不适合直接包裹标记；遇到提示时，缩小到普通文字后重新选择。标题、列表和引用的结构符号也应留在选区之外。

阅读视图支持原文为单行的纯文本段落，通过原生渲染器的源段落位置定位，重复词语也可以区分。段落中含有链接、加粗、已有标记或脚注时，请切换到编辑视图，选择具体位置的普通文字再操作。面板打开后如切换文件或原文发生变化，插件会拒绝保存，请关闭面板后重新选择。

将 [划线与备注示例](examples/划线与备注示例.md) 复制到笔记库，可以查看保存后的效果，并用其中未标记的段落体验操作。

源代码使用 Obsidian 的 [公开插件 API](https://github.com/obsidianmd/obsidian-api)，构建只需要 Node.js：在主题源目录运行 `node annotations/build.mjs`。单元测试运行 `node --test annotations/tests/core.test.cjs`。
