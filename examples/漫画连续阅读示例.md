### 换成自己的漫画

把图片放入笔记库，按页序逐行嵌入，每张图片单独一段，段落之间留一空行。阅读视图会居中排列图片，保留画面比例；图片不裁切，明确指定的宽高仍然有效。

```markdown
![[我的漫画/001.jpg]]

![[我的漫画/002.jpg]]
```

如果是需要无缝连接的条漫，在顶部 `cssclasses` 列表中再加一项 `inkstone-comic-strip`。它只去掉阅读视图中图片段落的页间距，正文与章节标题仍正常显示。需要保留页间空白的分页漫画，只用 `inkstone-comic` 即可。

用 `[!comic-nav]` Callout 放置目录或前后话链接，链接之间用空格分隔；窄分栏会自动换行。阅读宽度默认 `52rem`，可通过 CSS 代码片段中的 `--inkstone-comic-width` 调整。

连续图片排版用于阅读视图；实时预览与源码模式保留原生编辑行为。封面、章节和前后话链接均为手动编排，不会扫描文件夹或自动生成目录。
