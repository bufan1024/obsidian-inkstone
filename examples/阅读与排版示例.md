# 留一点时间给阅读

早晨打开窗，桌上的纸页被风吹起一角。楼下的店还没有营业，街道上只有送货车慢慢经过的声音。我把昨晚没有读完的笔记放到眼前，先看标题，再沿着几处划线回想：哪些话只是当时觉得有趣，哪些话经过一夜仍然值得留下。阅读不总是获取更多内容，有时也是给已经知道的事情一个安静的位置。

屏幕上的文字应该像一条平缓的小路，让目光不必反复寻找落脚点。字太小，读者会不自觉地凑近；一行太长，从行尾回到下一行开头就容易走失；段落挤在一起，思想的转折也显得模糊。舒适的排版不能替代好内容，却可以让内容少受一点阻碍。停下来读完一段，比快速扫过许多标题更容易留下记忆。

中文与 English 混排时，词语之间应当自然衔接。例如：用 Obsidian 记录一次 walk，写下沿途看见的 3 家小店，再把照片归入 `2026-10-20` 的笔记。标点、数字和缩写不需要抢走注意力；它们只要清楚，就能帮助我们重新找到当天的线索。遇到 unfamiliar 的词，也可以先读完句子，再回头查证。

==值得留下的句子，可以慢一点读。== **重要的判断**需要清楚，*尚未确定的想法*也应有自己的位置。~~这句话后来被新的证据推翻了。~~ 删除线保留思考的来路，修改之后的文字则继续向前。阅读中的标记最好有明确用途，过多的强调会让所有句子都变得一样响亮。[^mark]

午后，我把笔记分成两段：一段写看到的事实，一段写自己的解释。事实可以很小，比如一棵树比上周多了几片黄叶；解释则可能随着季节、经历或新的信息发生变化。把两者分开，并不会削弱文字的温度，反而让下一次回看更诚实。我们不必要求每一页都完整，但可以要求每一次记录都足够具体。

## 二级标题：把问题写清楚

这一节适合观察标题上下的留白。标题是阅读的路标：它告诉读者接下来要去哪里，也让返回这一页的人能快速找回方向。好的路标不必比道路更醒目，只需在需要的时候看得清楚。

### 三级标题：先留下线索

正文中的行内代码如 `readingMode`、`font-size: 18px` 应清晰易辨。中文标点（逗号、句号、括号）与 0123456789、ABC、abc 放在一起时，也应该保持顺畅的节奏。

#### 四级标题：再整理关系

把“发生了什么”和“为什么这样”分别记下来，常常就能发现还缺少什么。必要时，给这两个部分各留一行，允许暂时没有答案。

##### 五级标题：保留一个小问题

为什么有些短文值得反复阅读？也许是因为每次回看时，我们带来的经验已经不同。

###### 六级标题：细小但清楚的注记

小标题仍应可辨认。它可以帮助整理材料，而不必占据过大的空间。

## 列表与任务

- 读前：确认这次阅读想解决的问题。
- 读中：留下少量、有明确含义的标记。
  - 事实：可以查证的时间、地点和事件。
  - 判断：作者如何解释事实。
    - 证据充分时，记录推理过程。
    - 证据不足时，写下还需要确认的部分。
- 读后：用自己的话写一段摘要。

1. 找一个可以连续阅读十分钟的地方。
2. 读完一个自然段，再决定是否做笔记。
   1. 先写一句概括。
   2. 再添加必要的原文位置。
3. 合上页面，回忆刚才读到了什么。

- [x] 为今天的阅读留出时间。
- [x] 写下一个具体的问题。
- [ ] 整理尚未确认的内容。
  - [x] 找到原始资料。
  - [ ] 核对资料的日期与适用范围。
- [ ] 下次回看时，补上一段新的理解。

## 代码与公式

下面的代码只用于排版展示。注意缩进、注释、字符串和较长的一行。

```typescript
type ReadingNote = {
  title: string;
  minutes: number;
  finished: boolean;
};

const note: ReadingNote = {
  title: "留一点时间给阅读",
  minutes: 20,
  finished: false,
};

// 保留一条长行，用来检查代码块横向滚动。
const archiveKey = "reading_session_observation_archive_2026_10_20_without_manual_line_breaks_for_horizontal_scrolling";

function describeReading(item: ReadingNote): string {
  return `${item.title}：阅读 ${item.minutes} 分钟`;
}
```

行内公式示例：当每天阅读时间为 $t$，持续天数为 $n$ 时，总时间为 $T = nt$。公式应与正文基线和间距协调。

一天结束时，再读一次早晨的记录，可能不会得到新的结论，但会发现自己曾经认真看过什么。笔记的价值有时就藏在这里：它让短暂的注意力有了可以回访的地方。下一次打开这一页时，先从最想读的那一段开始。

[^mark]: 高亮用于强调少数值得回看的内容；脚注用于补充来源或旁注。查看脚注正文与返回链接，检查它们是否清楚可用。
